# flutter_habit_tracker

A simple Flutter UI/Application that tracks a user daily Habits & show strikes. This is basic project to practice the Application development in flutter.

## 🧰 Tools & Technologies Used

| Package / Widget | Description |
|------------------|-------------|
| **GetX**         | State management and routing |
| **SharedPreferences**          | platform-specific persistent storage for simple data |
| **LayoutBuilder**| Builds widgets based on the available constraints (responsive design) |
| **MediaQuery**   | Gets device screen size and orientation |
